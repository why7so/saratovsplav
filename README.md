# Сплав

Сайт туристической компании, которая организует сплавы по рекам Медведица и Хопёр в Саратовской области. Сезон — с июня по август.

Сайт: saratovsplav.dpdns.org

## Что это

Не просто одностраничник-визитка, а рабочий сервис с личным кабинетом, авторизацией, отзывами и чат-ботом для гостей. Главная страница рассказывает о маршрутах и программах сплавов и ведёт к форме записи.

Медведица — быстрая река с перекатами, подойдёт тем, кто хочет активности. Хопёр — тихая и спокойная, с заливными лугами, больше подходит семьям с детьми. На сайте представлены оба варианта, с разной длительностью и уровнем сложности.

## Страницы

- `index.html` — главная, с маршрутами, галереей и формой заявки
- `auth.html`, `profile.html` — вход и личный кабинет
- `chat.html` — чат-бот для вопросов
- `reviews.html`, `review.html` — отзывы клиентов
- `faq.html` — частые вопросы
- `privacy.html`, `personal-data-policy.html`, `marketing-consent.html` — юридические страницы

## На чём сделано

Фронтенд простой — html, css и js без сборки. Данные (пользователи, отзывы, заявки) хранятся в Supabase. Уведомления по заявкам отправляются через EmailJS. Есть свой трекер посещений сайта (js/site-tracker.js и sql/site_visits.sql).

## Структура

```
css/    — стили
js/     — логика: авторизация, чат, отзывы, трекер и т.д.
img/    — картинки и иконки
sql/    — схемы таблиц для Supabase
```
